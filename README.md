# Econometría Avanzada — course website

This repository contains only the public-facing website for the Universidad de los Andes course **Econometría Avanzada**.

The working course project remains in Overleaf and Dropbox. Selected public documents can be copied into `materials/` when they are ready for publication.

## Editing the site

- Edit the home page in `index.md`.
- Edit the course schedule in `schedule.md`.
- Edit the materials page in `materials.md`.
- Place public PDFs in the appropriate folder under `materials/`.
- Update site-wide settings in `_config.yml`.

The repository is prepared for GitHub Pages using Jekyll. Publishing will remain disabled while the site is private.
